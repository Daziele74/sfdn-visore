# SFDN Visore

Programma sperimentale di prova per il visore Pico Neo 3 Pro (Saccadic Fixator de Noialtri, Ottica Stefanucci, Sinalunga). Versione v0.5ABC.

**Tutto è sperimentale e non dà indicazioni cliniche.**

- Programma: `index.html` (un solo file, funziona offline, nessuna libreria esterna).
- Versioni precedenti (stesso indirizzo, stessi dati del browser): `versioni/SFDN_Visore_v0.5B2.html` e `versioni/SFDN_Visore_v0.5AB.html`.
- Istruzioni per la prova: `istruzioni/ISTRUZIONI_VISORE_v0.5ABC.md`.
- I dati dei soggetti restano nel browser del dispositivo e non sono mai caricati qui.
